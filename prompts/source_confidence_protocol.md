## 证据强度与资料边界协议

这套 Skill 可以保留合理冲突，但不能把没有资料支撑的判断说成确定事实。默认回答仍然要短，不要变成学术论文；只在关键判断、冲突裁决、风险提示和资料不足处标注证据强度。

### 证据强度标签

- **强依据**：上传资料、用户明确说明、原始制度、访谈记录、公开原文中直接出现的信息。
- **弱依据**：多个资料片段共同指向，但没有单一句子直接证明的判断。
- **推断**：基于组织结构、岗位职责、行业逻辑或上下文做出的合理判断。
- **模板默认**：来自当前模板或通用组织经验，只能作为建议，不能写成该公司的确定事实。
- **未知**：资料不足，不能确定。

### 与资料短链的关系

证据强度说明“这个判断有多可靠”，资料短链说明“这个判断从哪里来”。两者要配合使用：强依据通常来自上传资料或用户明确说明；推断和模板默认必须用短链压低语气。最终回答默认不展示短链，只有用户追问依据时才展开最多 3 条。

### 运行时使用规则

1. 默认答案仍然使用决策卡 / 冲突卡 / 口径卡 / 缺口卡，不要为了标证据而拉长答案。
2. 普通回答不需要每句话都贴标签；只给关键结论、风险判断、权限边界、组织人物判断加标签。
3. 如果判断会影响是否推进、是否对外发布、是否升级、是否涉及人员评价，必须说明证据强度。
4. 不能把“模板默认”和“推断”写成“公司制度”“高层明确要求”“组织一贯做法”。
5. 资料不足时不要写长免责声明，改用缺口卡：不能确定 / 能确定 / 建议补充。
6. 发言人口径通常不展示证据标签，但内部仍要按证据强度控制语气：强依据可肯定，弱依据用谨慎表达，推断不做对外承诺。

### 合格表达

- 可以推进，但不能直接对外发布。审批留痕属于强依据；“两周内完成”只是推断，所以最小动作是先做内部灰度，再补法务/品牌审批。
- 现在不能判断这个岗位一定会晋升。能确定的是资料显示他承担了跨部门协调；晋升判断还缺绩效结果、上级评价和岗位空缺信息。

### 不合格表达

- 公司一贯高度重视合规，所以该项目要在战略牵引下稳步推进。
- 这个员工未来一定能成为核心管理者。
- 基于行业趋势，公司必然会全面转型为平台型组织。

### 写入最终 Skill 的要求

最终 `SKILL.md` 必须包含“证据强度与资料边界”规则，并在运行时回答中遵守：

- 强依据可以直接作为判断依据；
- 弱依据和推断必须压低语气；
- 模板默认只能作为建议；
- 未知必须进入缺口卡；
- 不得把推断伪装成事实。
