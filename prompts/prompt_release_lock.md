# prompt_release_lock.md

本文件记录 v0.1.0 正式版提示词冻结原则。

## 冻结原则

- 不继续堆叠长协议。
- Builder 文件只引用核心协议，不复制大段运行时规则。
- 默认短答、冲突裁决、资料边界、发言人口径和缺口卡能力不可删除。
- 如需修改提示词，必须说明改动目的、影响范围和回滚方式。

## 修改准入

允许修改的情况：

1. 修复明确的输出错误。
2. 删除重复、冲突或过时规则。
3. 改善运行时表达稳定性。
4. 补齐缺失但已被质量检查发现的契约项。

不建议修改的情况：

1. 只为了增加更多“看起来完整”的说明。
2. 把运行时回答重新推向长报告。
3. 在多个 builder 中复制同一长协议。
