# 算疏智合 GUI 使用说明

## 启动

```bat
start_gui.bat
```

或：

```bash
python gui.py
```

## 使用流程

1. 配置模型：选择 Cloud 或 Local。
2. 检查模型连接。
3. 上传公司资料。
4. 选择组织架构。
5. 可选：插入组织成员资料。
6. 可选：批量导入成员目录。
7. 预览配置。
8. 确认生成。
9. 打开输出目录查看结果。

## 批量成员目录格式

```text
employee_docs/
├─ 张三/
│  ├─ 01_基本信息.md
│  └─ 02_项目经历.md
└─ 李四/
   ├─ 01_基本信息.md
   └─ 02_访谈记录.md
```

每个一级子文件夹会被识别为一个成员。根目录下散文件不会被自动合并为成员。

## 注意事项

- 不建议选择项目根目录、桌面或下载目录作为批量成员目录。
- 同名公司重复生成时，建议保留“生成前清理同名旧产物”选项。
- API Key 请只保存在本机，不要放入共享文件或公开仓库。
